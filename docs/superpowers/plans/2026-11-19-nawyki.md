# Nawyki — plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Moduł Nawyki z nawykami do odhaczenia i z wartością (waga w kg), seria, % z 30 dni, siatka kalendarza, wykres wagi z trendem, sekcja na „Dziś”.

**Architecture:** Czysta logika w `src/domain/habits.ts` (Vitest), akcje w `src/data/store.ts` wzorem wydatków, normalizacja starych rekordów w `db.ts`/`replaceAllData` (bez nowego magazynu IndexedDB). UI: sekcja w `Today.tsx`, ekran `Habits.tsx`, wykres w czystym SVG.

**Tech Stack:** Preact 10, TypeScript, Vite 6, Vitest 5 + fake-indexeddb, idb 8, Capacitor 8 (bez zmian natywnych).

**Spec:** `docs/superpowers/specs/2026-11-19-nawyki-design.md` — czytaj razem z tym planem.

## Global Constraints

- Rekordy: `id`, `createdAt`, `updatedAt`, `deletedAt` (tombstone); dni `DayKey` w Europe/Warsaw (`src/lib/date.ts`).
- Jeden żywy `HabitLog` na (`habitId`, `date`); poprawka wagi aktualizuje `value`, odznaczenie = tombstone; ponowne odhaczenie po tombstonie tworzy nowy rekord.
- Nawyki startowe (raz, `Meta.habitsSeeded`): „Witaminy” (`check`, `daily`, order 0), „Ważenie się” (`measure`, `unit 'kg'`, `daily`, order 1); naprawa znacznika, gdy nawyki istnieją — także po `replaceAllData`.
- Waga: akceptuj „82,4” i „82.4”, maks. 1 miejsce po przecinku; dla `unit === 'kg'` zakres 20–400, poza nim spokojna podpowiedź bez zapisu; inne jednostki: liczba > 0.
- Trend: średnia 7 dni (dziś włącznie) vs 7 dni wcześniej; „bez zmian” gdy |Δ| < 0,1; brak trendu gdy któreś okno puste.
- Brak przypomnień, brak czerwieni/wykrzykników, spokojny polski tekst.
- UI mobilne: pola ≥ 16 px, `inputmode="decimal"`, `enterkeyhint="done"`, cele dotyku ≥ 44 px, `:active` (bez niezabezpieczonego `:hover`), nic pod paskiem zakładek; kolory tylko przez zmienne CSS (tryb ciemny).
- Wykres: czyste SVG, bez nowej zależności.

## Review Focus

1. Seria dla nawyku codziennego, gdy dziś jeszcze nie odhaczony — nie spada do 0 przed końcem dnia (Task 2).
2. `timesPerWeek(3)` na granicy tygodnia (niedziela → poniedziałek) i po osiągnięciu 3 wpisów w tygodniu — znika z „Dziś”, % liczony tygodniami (Task 2).
3. Nawyk utworzony dziś — % z 30 dni nie pokazuje 3% za „brak” w dniach przed utworzeniem (Task 2).
4. Dwa szybkie wpisy wagi tego samego dnia (lub odznacz → zaznacz) — dalej jeden żywy wpis (Task 3).
5. Import starej kopii / stara baza bez `kind`, `unit`, `value`, `habitsSeeded` — normalizacja i jednorazowe zasianie (Task 1).

### Task 2: Logika nawyków (czysta)

**Files:** Create `src/domain/habits.ts`; Test `tests/habits.test.ts`

**Interfaces — Consumes:** typy z Task 1, `addDays`, `diffDays`, `isoWeekday`, `weekStart`, `dayKeyOf` z `src/lib/date.ts`, `isLive` z `src/domain/tasks.ts`.
**Produces:**
- `logsFor(logs: HabitLog[], habitId: string): HabitLog[]` (żywe), `logOn(logs, habitId, day): HabitLog | undefined`.
- `isDue(habit: Habit, logs: HabitLog[], day: DayKey): boolean` — reguły ze spec („Dzień zaplanowany”); dla `timesPerWeek` dzień z własnym wpisem też jest „due” (żeby odhaczenie było widać).
- `streak(habit, logs, today): number` — reguły ze spec („Seria”), nie przed `dayKeyOf(habit.createdAt)`.
- `completion30(habit, logs, today): number | null` — ułamek 0..1 lub `null` gdy 0 zaplanowanych.
- `calendarWeeks(habit, logs, today, weeks = 5): { day: DayKey; state: 'done' | 'missed' | 'off' | 'future' }[][]` — tygodnie pon–nd, ostatni zawiera `today`; `off` = niezaplanowany lub przed utworzeniem.
- `parseMeasure(input: string, unit: string | null): number | null` — reguły z Global Constraints.
- `weightTrend(logs: HabitLog[], habitId: string, today): { last: { value: number; day: DayKey } | null; avg7: number | null; delta: number | null }` (`delta` = avg7 − avg poprzednich 7; `null` gdy okno puste).
- `frequencyLabel(f: HabitFrequency): string` — `'codziennie'`, `'3 razy w tygodniu'` (`plural`: raz/razy), `'pn, śr, pt'`.
- `formatMeasure(value: number, unit: string | null): string` — `'82,4 kg'` (pl-PL, 1 miejsce po przecinku, zwykła spacja).
